AGAN PONSEL Flutter v0.7.0 Build 11

1. Unduh AGAN-PONSEL-Flutter-v0.7.0-Build11.zip ke folder Download Android.
2. Buka Termux, jalankan perintah SATU PER SATU:

cd ~/agan-build/agan_ponsel_flutter
unzip -o "/sdcard/Download/AGAN-PONSEL-Flutter-v0.7.0-Build11.zip"
git add lib pubspec.yaml scripts test .github/workflows/build-apk.yml README.md CHANGELOG.md INSTALL-TERMUX.txt
git commit -m "AGAN PONSEL Flutter v0.7.0 Build11"
git push origin main

3. Buka https://github.com/adelibra23/agan-ponsel-flutter/actions
4. Setelah build hijau, unduh artifact AGAN-PONSEL-v0.7.0-Build11-APK.
5. Backup data dari aplikasi sebelum update. Jangan uninstall aplikasi lama.
6. Update APK memerlukan applicationId dan signature yang sama seperti APK terpasang.

Pengingat piutang muncul dalam aplikasi, belum muncul sebagai notifikasi Android ketika aplikasi tertutup.
