AGAN PONSEL Flutter v0.4.0 Build5
================================
1. Unduh ZIP ke folder Download HP.
2. Buka Termux. Masuk ke proyek:
   cd ~/agan-build/agan_ponsel_flutter
3. Ekstrak file baru:
   unzip -o /sdcard/Download/AGAN-PONSEL-Flutter-v0.4.0-Build5.zip
4. Periksa perubahan:
   git status --short
5. Kirim semua kode sumber baru:
   git add lib pubspec.yaml README.md .github/workflows/build-apk.yml scripts test INSTALL-TERMUX.txt
   git commit -m "AGAN PONSEL Flutter v0.4.0 Build5"
   git push origin main
6. Di browser buka:
   https://github.com/adelibra23/agan-ponsel-flutter/actions
7. Tunggu centang hijau, unduh artifact APK, ekstrak ZIP, pasang app-release.apk.

PENTING: Jangan uninstall versi lama yang menyimpan data. Backup dari
Pengaturan > Backup & Restore dulu. APK dari GitHub run berbeda mungkin
tidak bisa memperbarui app terpasang jika belum menggunakan keystore
rilis permanen yang sama. Uji dahulu tanpa data operasional penting.
