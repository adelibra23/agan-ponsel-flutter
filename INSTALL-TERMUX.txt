AGAN PONSEL Flutter v0.5.0 Build 7
===============================

1. Download AGAN-PONSEL-Flutter-v0.5.0-Build7.zip ke folder Download Android.
2. Buka Termux dan jalankan:

cd ~/agan-build/agan_ponsel_flutter
unzip -o "/sdcard/Download/AGAN-PONSEL-Flutter-v0.5.0-Build7.zip"
git status --short
git add lib pubspec.yaml scripts test .github/workflows/build-apk.yml README.md CHANGELOG.md INSTALL-TERMUX.txt
git commit -m "AGAN PONSEL Flutter v0.5.0 Build7 barcode foto PIN"
git push origin main

3. Buka GitHub -> repository agan-ponsel-flutter -> Actions.
4. Pilih build terbaru -> jika hijau, buka Artifacts dan unduh APK.

CATATAN: Pastikan database telah dibackup sebelum mengganti atau menghapus APK.
Jangan uninstall versi lama untuk upgrade! Update APK butuh applicationId dan kunci tanda tangan yang sama.
Jika GitHub Actions merah, lihat log error. File APK belum diverifikasi berjalan.
