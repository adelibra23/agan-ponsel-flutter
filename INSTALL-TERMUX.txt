2. Buka Termux, jalankan:

cd ~/agan-build/agan_ponsel_flutter
unzip -o "/sdcard/Download/AGAN-PONSEL-Flutter-v0.8.0-Build12.zip"
git add lib pubspec.yaml scripts test .github/workflows/build-apk.yml README.md CHANGELOG.md INSTALL-TERMUX.txt

3. Buka https://github.com/adelibra23/agan-ponsel-flutter/actions
4. Setelah workflow hijau, unduh artifact AGAN-PONSEL-v0.8.0-Build12-APK.
5. Backup data penting SEBELUM memperbarui APK.
6. Jangan uninstall aplikasi lama sebelum memastikan backup bisa dipulihkan.
7. Instalasi UPDATE memerlukan package ID dan sertifikat penandatanganan yang sama.

Jika tidak ada perubahan saat git commit, periksa posisi ekstraksi ZIP dengan `ls lib/agent`.
Jika GitHub Actions merah, buka langkah merah pertama dan kirim log error.
